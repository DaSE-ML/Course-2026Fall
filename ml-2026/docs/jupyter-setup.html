本地 JupyterLab

请先进入本目录 ml-2026，再双击 启动课程.command（macOS）或 启动课程.bat（Windows），会先打开课件入口（index.html）再启动 JupyterLab。保持启动窗口开启——关闭它 JupyterLab 会一并退出。结束使用时，在该终端按 Control+C 并确认关闭服务器。

也可以在终端手动执行：

cd '/Users/momo/Documents/workspace/教学/2026机器学习与概率统计-本科'
./start.sh

选择内核

  • 第 1–9 章实验：选择 ecnu-ml（机器学习课程 Python 3.14），对应课程目录 .venv（scikit-learn 1.9.0，课件数字锚定于此）。
  • 第 10 章 Hugging Face / 预训练模型实验：选择 ecnu-hf（机器学习课程 HF Python 3.12），对应 .venv-hf。
  • 两个内核已注册到用户级 Jupyter 目录，无论 JupyterLab 从哪个环境启动都会出现在内核列表；第 1–9 章切勿选 HF 内核，否则数字与课件对不上。
  • 在 Notebook 菜单 Kernel → Change Kernel 切换。先使用 File → Save Notebook As 保存练习副本，避免覆盖带参考输出的教师版本。
  • Shift+Enter 运行当前单元。完整复现使用 Kernel → Restart Kernel and Run All Cells。

环境分开是为了保留两组已经验证过的依赖版本，避免 PyTorch 和基础实验互相影响。服务只监听本机 127.0.0.1（启动课程.command 启动的实例免令牌，仅本机可访问）；无需上传课程文件。

虚拟环境保存在课程目录，不再依赖 /private/tmp 的临时虚拟环境，但仍依赖创建它们的本机 Python：基础环境使用 Homebrew Python 3.14，HF 环境使用 Codex 配套 Python 3.12。将整个课程目录复制到其他电脑后应重新创建环境，不能直接搬运虚拟环境。

首次执行某些实验可能需要下载数据或模型，具体以各 Notebook 说明为准。
