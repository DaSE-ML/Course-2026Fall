线性模型：ŷ = wᵀx + b

线性模型把每个特征乘以对应权重，再把结果相加并补上截距，输出一个连续预测值：

ŷ = wTx + b

一个特征时，它就是直线 y=kx+b：w 决定斜率；b 是基础偏移（截距），决定直线整体上下移动。所有特征为 0 时，模型输出就是 b，但这个输入不一定具有现实意义。多个特征时，wᵀx（读“w 转置乘 x”）表示把所有“特征×权重”加总。图中 x 是房屋特征，ŷ 是预测，真实价格记作 y；w、b 通常由训练确定，本页用 0.8、10、5 演示计算。

实际参数从哪里来？训练会比较预测价格和真实成交价，根据差距调整参数。下一页先看：怎样衡量预测与真实的差距。

损失：量化预测与真实的差距

损失（loss）：衡量预测偏离真实值程度的数值，损失越小，预测越准。训练的第一步，就是把损失写成参数的函数。

最小二乘：选择残差平方和最小的直线

最小二乘法是在所有可能的直线中，选择残差平方和最小的一条。残差（residual）就是一个样本的预测值与真实值之差。

  1. 选一组参数 w、b，得到一条候选直线；
  2. 用直线计算每个样本的预测值 ŷ；
  3. 计算残差 r=ŷ−y，再将所有 r² 相加；
  4. 继续调整 w、b，直到平方和不能再减小。

为什么要平方？正负残差不会相互抵消，而且较大的误差会受到更重的惩罚。图中候选线 A 的残差平方和（SSE）=10，候选线 B 的 SSE=4，所以 B 更符合这组数据。

延伸：损失为什么偏偏取平方？换一个视角（最大似然，maximum likelihood）：假设每条成交价围绕预测值上下浮动、浮动服从高斯钟形：预测偏得越远，“眼前这批成交价出现得有多可能”就按平方级往下掉。于是，让这批数据最可能出现的参数，恰好就是让残差平方和最小的参数：两种说法在数学上完全等价。完整推导见 CS229 讲义的 Probabilistic Interpretation 一节。

为什么用平方，不用绝对值？

上一页用平方消除残差的正负号。其实办法不止一个：把每条残差取绝对值再求和，∑|rᵢ|（r 为残差），同样不给正负抵消的机会，也能比较候选直线的优劣。

两版打分选哪个？取舍标准是可导性。|x| 在 x=0 处有个尖点：左边斜率是 −1，右边是 +1，这一点不可导，微积分在尖点处求不出极值；x² 处处光滑，任何一点都有导数，“令导数为零找最低点”一路畅通。

所以平方损失保住的是“求导”这条路线：『正规方程』一页对损失求导置零，后面的梯度下降每一步都靠导数指方向，前提都是损失处处可导。

正规方程：一步解出的闭式解

参数不迭代也能一步直接解。最小的例子：两点 (1, 3)、(3, 7)，求直线 ŷ=wx+b 过这两点，代入得两条方程：

w + b = 3　且　3w + b = 7　→　两式相减 2w=4，得 w=2、b=1

验算：x=1 时 ŷ=3，x=3 时 ŷ=7，两条残差都是 0，MSE=0。两个未知数两条方程，中学消元就能解；这步消元的矩阵版就是正规方程（normal equation）：

一个公式直接算出参数的解，叫闭式解（closed-form solution）。

矩阵形式把 n 个样本一次算完：X ∈ ℝn×d 为 n 行 d 列的特征矩阵（每行一个样本），y ∈ ℝn、w ∈ ℝd。第 2 章 digits 的 X 有 64 列，即 d=64。

蒙眼下山——往哪边走，迈多大步

蒙着眼站在山坡上，你只能感觉到脚下的坡度。策略只有一条：每一步都朝最陡的下坡方向迈。步子别太大，会一步跨过谷底；也别太小，天黑还在半山腰。

梯度（gradient）就是坡度，学习率（learning rate）就是步长。这个比喻接下来管三站：往哪边走（梯度）、怎么迈步（更新式）、迈多大（学习率三档）。

梯度：往哪边走降得最快

并非所有模型都能写出闭式解，所以还需要迭代求解。把双参数压到一个参数看方向：L(w)=(w−3)²，最低点在 w=3。站在 w=0 这一点，往哪边走是下坡？答案在斜率里。导数（derivative）就是曲线在这一点的斜率：∂L/∂w = 2(w−3)，∂ 读“偏”，含义同 d，只提醒式子里还有别的量。

w=0 处：2×(0−3) = −6　（负号＝此处下坡朝 w 增大的方向）

多个参数时，把每个参数方向上的导数排成向量，就是梯度（gradient）：它指向损失上升最快的方向；掉个头，负梯度就是下降最快的方向。

读图：横轴是参数 w，纵轴是损失；蓝线是 L(w)=(w−3)²，橙点是从 w=0 出发的 3 步落点 0.6 → 1.08 → 1.464（步长 η=0.1，下一页正式介绍），逐步逼近最低点 3。数据：03a-gradient-descent.ipynb（scikit-learn 1.9.0，default_rng(42)）：落点序列见 cell 8，与手算同一例子。

梯度下降更新式：一步怎么走

方向有了，还差步长。梯度下降（gradient descent）每步沿负梯度方向挪一段，挪多远由学习率（learning rate）η（读“伊塔”，eta）决定：

w ← w − η·∂L/∂w

用这套更新式前，先备好两样东西。

记号：把截距 b 并进权重向量——给每个样本添一个恒为 1 的常数分量，单样本的 X 记作 [1,1]，第一个 1 乘截距 b，第二个 1 是特征值 x；w=[0,0] 的两个分量分别管截距和斜率。

梯度公式：单样本损失 L=(ŷ−y)² 对 w 求导（链式法则，本课记结论）：∂L/∂w = 2(ŷ−y)·x，误差越大、样本值越大，推力越大；多样本把每个样本的梯度取平均：

截距 b 的偏导走同一条链式法则，只是少了乘 x 这一环：∂L/∂b = (2/n)Σ(ŷᵢ−yᵢ)，单样本时完全由残差本身决定：残差为负就把 b 调大，残差为正就调小。

两样备齐，手算一步（单样本 x=1、y=3，起点 w=[0,0]，取 η=0.1）：

  1. 预测：ŷ = 0×1 + 0×1 = 0，残差（预测减真实）为 −3，损失 9；
  2. 梯度：2×(−3)×[1,1] = [−6,−6]，截距、斜率各得一份往上调的推力；
  3. 更新：w ← [0,0] − 0.1×[−6,−6] = [0.6, 0.6]；
  4. 验证：新预测 0.6×1 + 0.6×1 = 1.2，比 0 更接近 3。
error = X @ w - y                 # (n,) 个残差
grad = 2 * X.T @ error / len(y)   # 各参数方向的平均梯度，形状 (d+1,)
w = w - eta * grad                # 每个参数各走一步

记号：@ 表示矩阵乘法，.T 表示转置。80 个样本用同款三行（X 含常数列，形状 (80,2)）：更新前损失 4.19，一步之后 3.14。平方求导掉下来的因子 2 已经在梯度式里；代码里漏写它，步子会系统性偏小一半。

数据：03a-gradient-descent.ipynb（scikit-learn 1.9.0，default_rng(42)）：单样本手算见 cell 2 与 cell 5；三行代码与损失 4.1879 → 3.1395、梯度形状 (2,) 见 cell 13。

梯度下降全景：四步看懂训练

  1. 模型：w 和 b 确定一条候选直线，对应参数空间中的一个点。
  2. 损失：均方误差汇总预测偏差；曲面越低，参数越合适。
  3. 梯度：两个偏导数组成 ∇L，说明 w、b 分别怎样改变会使损失上升最快。
  4. 更新：沿 −∇L 调整参数；学习率 η 决定每一步的长度，重复更新使损失逐步减小。

特征尺度：大数值让训练发散

先猜：把输入 x 放大 100 倍、目标不变，原来好用的 η=0.1 还稳吗？

读图（对照图例逐线看）：original x, eta=.1 正常下降；100x, eta=.1 直接发散；100x, eta=.0001 能下降但慢。

原因在梯度式里：∂L/∂w 含因子 x，x 放大 100 倍梯度跟着放大 100 倍，同一个 η 步子就过大。安全步长还受损失曲线弯度的影响。弯度即曲线的弯曲程度，由 x² 项的平均值决定，x 放大 100 倍就把弯度放大约 100²=10⁴ 倍；弯度大 10⁴ 倍，安全步长的上界就缩到约万分之一，所以 η 要从 0.1 量级缩到 0.0001 量级（图中 eta=.0001 实测已稳），而不是只除以 100。

多特征尺度悬殊时更隐蔽：一步对 w₁ 合适、对 w₂ 过大，落点在山谷两侧来回弹，轨迹呈锯齿形（zigzag），损失忽降忽停。这正是第 2 章先做 StandardScaler 的优化理由：把每列拉到相近范围，一个 η 才对所有特征都合适。

z 分数与 StandardScaler：让特征尺度可比

StandardScaler 是 scikit-learn 中按列做 z-score 标准化的工具：先在训练集计算 μ、σ，再用 (x−μ)/σ 转换所有数据。

一列训练数据：[2, 4, 6]。均值 μ=4；按本页口径，标准差 σ=√[(4+0+4)/3]≈1.63。

z = (x − μ) / σ

z 分数表示一个值离均值几个标准差：负值在均值下方，正值在上方。这里 6 的 z 分数约为 1.22。

标准化按列进行；图中只展示一个特征列。

读图结论：训练集变换后，每个非恒定特征的均值为 0、标准差为 1；验证集和测试集沿用训练集的 μ、σ，所以均值不必为 0、标准差不必为 1。这样能让不同特征处在更可比的尺度，学习率也更容易设定。

z 分数本身不要求数据服从正态分布；正态分布只影响它的概率解释。

随机梯度下降与小批量

前几页每一步用全部 n 个样本，叫批量梯度下降（batch gradient descent）。n 上千万时一步太贵。随机梯度下降（Stochastic Gradient Descent, SGD）每步只抽 1 个样本算梯度；小批量（mini-batch）每步抽 B 个（常用 32 或 64），是深度学习的默认做法。

随机抽一两个样本，方向可靠吗？手算验证（当前点仍是 w=[0,0]）：样本 A（x=1, y=3）梯度 [−6,−6]；样本 B（x=2, y=1）预测为 0、残差 −1，梯度 [−2,−4]。

两条路线怎么选：正规方程 vs 梯度下降

『正规方程』与『梯度下降更新式』两页各给了一条求解路线，它们都能拿到参数，代价与适用条件不同：

路线怎么解学习率代价与适用
正规方程闭式解，一步算出不需要特征数很大时矩阵求逆代价高（约 O(d³)，随特征数三方增长），适合特征数少

多项式特征：直线不够弯怎么办

换个数据集做后半个章节：30 个点，x 在 0 到 1 之间，真实关系 y=cos(1.5πx) 加标准差 0.1 的随机噪声（生成参数见 03-regression-gd.ipynb cell 2，np.random.seed(0)）。这份数据带弯，直线拟合不动。

办法：把 x²、x³ 这类幂次当新特征列加进 X。一行代码完成，形状从 (30, 1) 变 (30, 4)（cell 5 实测）：

from sklearn.preprocessing import PolynomialFeatures
features = PolynomialFeatures(degree=4, include_bias=False)
X_column = X[:, None]                        # (30,) → (30,1)，一行一个样本
expanded = features.fit_transform(X_column)  # 4 列：x, x², x³, x⁴

展开后模型对参数仍是线性：ŷ = wᵀx + b 的结构原样不动，多了几个权重而已，但画出的曲线能弯。加到几次方，就是模型复杂度（model complexity）的旋钮：阶数越高，能表达的弯越夸张。下一页就用 1、4、15 三档拧这个旋钮。

欠拟合与过拟合：看曲线下诊断

三个阶数各拟合同一份 30 点数据：1 阶（直线）、4 阶、15 阶。读图三面板：蓝点是带噪声的观测，蓝线是模型学到的曲线，橙线是生成数据的真实函数。现实中你看不到橙线，它只存在于本教学例，所以最终不能靠“离橙线近”来选模型。

欠拟合（underfitting）：模型太简单，连主要趋势都学不到，训练误差和新数据误差都高，1 阶面板的直线追不上弯。过拟合（overfitting）：模型把训练样本的细节（含噪声）当规律背下来，训练误差很低、换新数据反而变差，15 阶面板的曲线挨个迁就每个蓝点。这两个定义是操作性的：判断只看“训练误差高不高、换新数据掉不掉”两个量。

至于“复杂模型为什么会背细节”，机理第 6 章正式命名（偏差与方差），本章只立操作性定义。图标题里每个面板标注的 MSE(±) 是什么分数，下一页揭晓。

用 CV 选阶：10 折够用版

三个阶数谁好，要一个公平考官。训练误差偏向复杂模型（15 阶训练误差必然最低），不能用来选。交叉验证（cross-validation, CV）够用版：把训练数据切 10 份，每份叫一折（fold），轮流拿一折当小考卷、其余 9 折训练，10 次成绩取平均。每轮当考卷时模型都从零重训，不会提前见到考卷内容。

1 阶0.408 ± 0.425
4 阶（选定）0.0432 ± 0.0708

外推警示：能算出数，不等于有依据

回到『本章定位』一页的房价数据：24 条成交记录覆盖约 30 到 150 平米。在范围内用直线估价，有数据支撑，这叫插值（interpolation）；沿着同一条直线问范围外的面积，缺少该范围数据支持，这叫外推（extrapolation）。

读图：实线段画在 30–150 ㎡（有成交记录），虚线是同一条直线伸进阴影区的部分（150–300 ㎡，无成交记录）。沿直线算 300 ㎡，读数约 950 万：数字能算出来，那个区间却没有任何一条成交记录。面积与价格的关系在那里可能是另一条线（更平缓的斜率或不同截距），别墅市场与普通住宅市场的结构并不相同。

小故事：谷神星与最小二乘

1801 年 1 月，朱塞佩·皮亚齐在巴勒莫发现谷神星；观测约 40 天后，它靠近太阳而无法继续观测。24 岁的高斯据这些观测推算轨道。12 月 7 日，天文学家冯·察赫在高斯预报的位置附近重新找到谷神星。

这次成功让高斯在天文学界声名鹊起。最小二乘法随后成为处理观测误差、估计轨道参数的重要工具：勒让德在 1805 年首次发表并命名它；高斯在 1809 年系统阐述相关方法，并称自己早在 1795 年已使用它。两人的优先权之争持续多年。

小故事：为什么叫“回归”？

1885 年，高尔顿（Francis Galton）研究父母身高与子女身高：特别高的父母，子女平均比父母略矮；特别矮的父母，子女平均比父母略高——两代都向人群平均值靠拢。这一现象后来被称为向均值回归（regression to the mean），拟合出的直线也叫 regression line，“回归”这个名字沿用至今。

读图：合成示意数据。实线是拟合直线，斜率约 0.56，明显小于 1：右上段落到对角虚线（y = x）下方，左下段抬到对角线上方，两端都朝中间收。

今天的提醒：极端表现之后的回落，往往是均值在起作用，不一定有特别的原因。球员第二年成绩下滑、门店促销后的客流回落，都可能出于同一个机制。
