MODULE / CHAPTER · 知识优先

章节标题：先建立判断，再执行动作。

用一句话说清学生完成本章后能解释、选择或验证什么。

[示意｜AI 生成/合成｜非真实界面、非真实实验结果]

判断 · 为什么

证据不是结论的装饰，而是下一步的依据。

先读输出中的状态，再决定是否继续执行；不要用“看起来成功”代替验证。

01 / CONTEXT位置正确

知道当前命令在哪个项目中运行。

02 / RULE规则可见

能指出当前操作应遵守的约束。

03 / OUTPUT结果可读

区分成功、警告与需要处理的错误。

04 / NEXT动作可证

下一步能被终端、diff 或检查结果验证。

来源：本章离线材料 · 操作证据示例

比较 · 选择

把模糊的“试试看”改成可回看的闭环。

工作方式留下的证据下一步
直接执行只有印象难以复盘
先读—再做—后验输出、diff、检查可解释地推进
读取上下文→说明动作→观察证据→决定下一步

证据 · 终端

让输出回答“发生了什么”。

讲解时圈出命令、状态和下一步，而不是把整屏输出当作结论。

terminal · read-only example
$ git status --short
✓ working tree clean

$ node courseware/tools/verify-courseware.mjs
✓ 课件静态检查通过：已检查 10 个章节
来源：本章离线演示 · Git 与课件检查输出
