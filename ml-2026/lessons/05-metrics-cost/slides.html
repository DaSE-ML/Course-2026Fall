查准率与召回率

查准率，也称精确率／精度（Precision）

预测正类中，真正是正类的比例。

Precision = TP / (TP + FP)

召回率，也称查全率（Recall）

真实正类中，被模型找回的比例。

Recall = TP / (TP + FN)

Precision 看名单准不准，Recall 看正类找回多少；两者并非必然一升一降。查准率勿与准确率（Accuracy）混淆。

回到UCI数据：Precision＝326/453≈72.0%；Recall＝326/1,327≈24.6%。名单的分母和实际违约人数的分母不同。

F1 分数：把查准率与召回率合成一个数

上一页留下一个追问：查准率与召回率是两个数，比较模型时常常要合成一个数。F1 分数（F1 score）就是那个合成数：两者的调和平均（harmonic mean）。

任一为 0，F1 就是 0；它不超过算术平均 (P+R)/2，P=R 时才取等，较小的数把 F1 拉低。

算术平均为何不行？把全部客户都报为违约：R=100%，P 只有 22.1%（6000 名客户中违约 1327 名），算术平均 0.61，F1 只有 0.36，滥报换来的召回被如实压低。

F1 比 Accuracy 更适合不平衡数据：它只关注正类的 Precision 和 Recall，不会被多数类主导。全报“未违约”时 Accuracy 高达 77.9%，F1 却是 0。但它不是专为不平衡数据设计的：它忽略 TN，误伤正常客户的代价再高也反映不出；它默认 Precision 和 Recall 同等重要；它还依赖分类阈值，阈值一变，F1 就跟着变。负类的表现要靠本讲后面的代价核算。

F1 随阈值怎么变？下一页把 F1 逐阈值画出来，看它如何帮你挑平衡的工作点。

🧮 若 P=0.6、R=0.2：算术平均与 F1 各是多少？谁更接近较小的 R？

参考答案

算术平均 (0.6+0.2)/2=0.4；F1=2×0.6×0.2/(0.6+0.2)=0.30。F1=0.30 低于算术平均，比 0.4 更接近较小的 R=0.2——调和平均被较小值拉低。

ROC 曲线与曲线下面积（ROC-AUC）

ROC-AUC 是 ROC 曲线下的面积，也等于全部正负样本配对的平均得分（同分记半分）。本页介绍面积计算，下一页介绍等价的配对法。

先取相邻两个ROC点，再算宽度与两端平均高度，相乘得到这一块面积；最后将各块相加。水平段下方是矩形，竖直段面积为 0；同分组可能产生斜线段。

AUC=∑j=1m(xj−xj−1)·yj+yj−12

xⱼ＝FPR，yⱼ＝TPR，m 为区间数。每项＝宽度 × 两端平均高度；水平段两端等高，就是矩形面积。

sklearn计算流程（展开查阅）
  1. roc_curve 按分数排序，逐步降低阈值；同分样本一起加入预测正类名单。
  2. 统计 TP、FP，分别除以真实正类、负类总数，得到 TPR、FPR。
  3. auc 用上式求和，即梯形法；矩形是其特殊情况。

roc_auc_score(y_true, y_score) 封装以上步骤；y_score 为预测概率或决策分数。本例 ROC-AUC≈0.720。

同分组：模型分数完全相同的一组客户；若同时含正、负样本，降低阈值时会一起报出，TPR 与 FPR 同时上升，形成斜线段。

AUC＝1：完美排序；＝0.5：随机水平；＜0.5：比随机差；＝0：完全反向。

平均查准率（AP）：汇总 PR 曲线

平均查准率（Average Precision, AP）按召回率增量加权汇总查准率：将每步的召回率增量乘以对应查准率，再求和。

j 按阈值降低的顺序编号；Pⱼ 是 Precision，Rⱼ 是 Recall，R₀=0。新增正类使 Recall 增加，这一步的名单越准，贡献越大。

蓝色矩形面积之和就是平均查准率（AP），约为 0.493。宽为召回率增量，高为对应查准率；放大图展示连续 5 个真实区间。

基本率（base rate）是真实正类比例。本例违约比例为 22.1%；所有客户分数相同时，AP=0.221，可作为比较基线。

扩展阅读：平均精度均值（mean Average Precision, mAP）是多个 AP 的平均值，用于汇总多个类别的识别表现，常见于目标检测，例如同时检测图像中的猫、狗和汽车。通常先计算每类 AP，再对类别取平均：猫 AP=0.8、狗 AP=0.6，则 mAP=0.7。检测时还要判断预测框与真实框是否匹配；交并比（IoU）衡量两框的重叠程度。COCO 常进一步对多个 IoU 阈值下的结果取平均，因此比较 mAP 时应确认评价规则一致。COCO 评价说明 ↗

概率校准（probability calibration）关注：预测70%的人群，实际是否也约有70%违约？

  1. 模型预测：同一组100位客户，每人预测违约概率都是70%。
  2. 观察实际：40人违约，占40%；图中每个小人代表10人。
  3. 比较两者：70% − 40%＝30个百分点，这组高估了风险。

逐组比较预测与实际，找出高估或低估的概率区间。

布里尔分数（Brier Score）

分组比例吻合，还不能说明每个人的概率预测都好。接下来比较逐个样本的概率误差。

布里尔分数（Brier score）是预测概率与0/1标签的平均平方差，越小越好；无需先选分类阈值。

n是样本数；p为预测违约概率，y为实际标签（违约1、未违约0）。

ECE衡量分组校准偏差；Brier评价逐个样本的概率误差。Brier更低，不一定说明各组概率都更准。两者都是评价指标，不会自动修正概率。

⚠️ 布里尔分数更低，就能证明每个概率箱都更准吗？

参考答案

不能。Brier是全部样本概率误差的平均，同时受区分能力与校准影响，某个概率组仍可能不准；还需结合可靠性图、ECE和人数。

对数损失（Log Loss）

在本课二分类中，对数损失（log loss）与二元交叉熵是同一个公式：第4讲用它训练模型，本讲用它评价预测概率。

n：样本数；i：样本编号；pi：第i个样本的预测违约概率；yi：实际标签（违约1、未违约0）。

同一位实际未违约客户：给违约概率99%时，真实类别概率只有1%，损失约4.61；给违约概率60%时，真实类别概率为40%，损失约0.916。真实类别概率越小，惩罚越大。

📉 为什么一个很自信的错判，可能拉高整批对数损失？

参考答案

因为模型给真实类别的概率很小，负自然对数会很大。y=0时，应取1−p；p=0.99给真类概率0.01，损失约4.61；p=0.60给真类概率0.40，损失约0.916。

本式对应第4讲的交叉熵损失（CE loss，p11）；这里用于评价概率，越小越好。模型指标对照：Logistic 0.472，分箱贝叶斯0.557，kNN 3.66。kNN的0或1概率可能导致很自信的错判，受到较大惩罚；它不是纯校准指标。

每天只能复核600人，该选哪个模型

现在回到p1的600人复核问题。先以“选满600人、实际命中最多”为目标，公平比较三种模型。

面对同一批6,000名UCI验证客户，每天只能复核600人。如果希望在这600人中尽量多发现实际违约客户，该选哪个模型？

直接用0.5阈值，各模型报出的名单长度不同，可能超过600人，也可能没用满名额。

先统一选择规则：各模型按预测违约概率从高到低排序，各选前600人，再比较名单中的实际违约人数。

这叫前K名选择（Top-K selection），本例K=600。它把比较条件固定为相同人数，后面用前K查准率与召回率评价名单。

💼 每个模型都选600人，怎样判断哪个模型更适合复核？

参考答案

比较每份600人名单命中的实际违约人数。人数与真实正类总数相同时，命中更多的模型，其前K查准率和召回率都更高；本次选择证据随后由真实UCI表给出。

本轮先选满600人作对照；“最多600人”也允许少选，后面结合代价讨论。K是复核名额，不是kNN的邻居数。插画为场景示意。

从调整阈值到加权训练

调整阈值发生在预测后。如果希望模型在训练时更重视违约样本，可以给交叉熵损失加上类别权重（Class Weight）：

w₁、w₀分别为违约、未违约样本的权重；都为1时恢复普通交叉熵。

右例设 w₀＝1、w₁＝4，让违约样本在训练损失中的权重为未违约样本的4倍。

调整阈值：保留已训练的分数，只改变分类结果。
类别加权：改变训练损失，重新拟合模型。

重训后，logit、预测概率和排序都可能改变，须重新评价并选择阈值。权重4不保证漏报减少4倍，也不自动满足600人上限。

⚠️ 加类权重重新训练后，可以沿用原模型的AUC、校准和最佳阈值吗？

参考答案

不能直接沿用。类别权重改变训练目标，重训后的分数与概率可能变化，需要重新评价 AUC 和校准，并重新选择阈值。

代码示例：在分类器中设置权重

model = make_pipeline(
    StandardScaler(),
    LogisticRegression(
        # 字典格式：类别标签: 训练权重
        # 0: 1 → 未违约样本权重为1
        # 1: 4 → 违约样本权重为4
        class_weight={0: 1, 1: 4},
        max_iter=1000,
        random_state=42,
    ),
)

# 改变权重后，必须重新训练
model.fit(X_fit, y_fit)
p = model.predict_proba(X_valid)[:, 1]

默认 class_weight=None，两类权重相同。也可设为 class_weight="balanced"，按训练集类别人数自动加权：每类权重＝总样本数 ÷（类别数 × 该类人数），让少数类每个样本的权重更大。
