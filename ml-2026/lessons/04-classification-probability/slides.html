先从概率说起：几率 odds

二分类标签记作 Y∈{0,1}。令 p=P(Y=1) 表示事件（正类）发生的概率，那么不发生的概率是 1−p。几率（odds）比较发生与不发生：

odds = p/(1−p)　　反过来：p = odds/(1+odds)
事件（示例概率）发生 p不发生 1−podds
抛硬币为正面0.50.51
掷骰子出 61/6 ≈ 0.1675/6 ≈ 0.8330.2
下雨（假设）0.80.24
中奖（假设）0.010.99≈ 0.0101

odds=1 表示发生与不发生一样可能；odds=4 表示发生的可能性是不发生的 4 倍；odds=0.2 表示发生的可能性是不发生的 1/5。对于 0<p<1，odds 在 (0,+∞)；当 p 趋近 0 或 1，odds 分别趋近 0 或无穷大。

🧮 若某事件的发生概率是 0.75，它的 odds 是多少？

参考答案

0.75/(1−0.75)=3：发生的可能性是不发生的 3 倍。

从 odds 到 logit：概率如何接上线性模型

对几率 odds 取自然对数，得到对数几率（log-odds），也叫 logit：

logit(p) = ln[p/(1−p)]

Logistic 回归假设：给定特征 x 后，正类概率的对数几率是特征的线性组合：

z = wTx + b = logit(p(x))

从 logit 反解回概率，得到 Logistic sigmoid 函数：

p(x) = 1/[1+e−z] = σ(z)

第一式用一般概率 p 定义 logit；模型的概率依赖特征，故写作 p(x)。左右图纵轴都是 z，刻度相同；左图只改变一个特征作示意，右图展示 p(x) 取 logit。p(x)<0.5 时 z<0，p(x)>0.5 时 z>0。信用卡例有 8 个特征，不能由左图完整表示。Notebook：从几率到 logit，再到概率。

两种 S 形函数：Logistic sigmoid 与 tanh

sigmoid 泛指一类 S 形函数；上一页得到的 Logistic sigmoid 是本课二分类概率输出所用的曲线。右图将它与 tanh 放在同一坐标系比较：两者都是 S 形，但值域与对称中心不同。

Logistic sigmoid 关于点 (0, 0.5) 中心对称，满足 σ(−x)=1−σ(x)；tanh 关于原点中心对称，满足 tanh(−x)=−tanh(x)。两者关系为：

σ(x) = [1 + tanh(x/2)] / 2

因此 tanh 经缩放、平移后与 Logistic sigmoid 完全相同，并不是另一种不同的概率曲线；tanh 原始输出含负值，不能直接当作概率。在简单循环神经网络（RNN）中，tanh 可以把当前输入与上一时刻保留的信息合成为新的隐藏状态（hidden state）。在一些基础 RNN 中，tanh 常用作状态更新时的激活函数。

扩展阅读：PyTorch 官方 RNN 文档。

右图标出两曲线的值域、对称中心和 x=±1 的函数值。广义 sigmoid 函数族还包括其他 S 形曲线；本课后续所说的 sigmoid 特指 Logistic sigmoid。Notebook：Sigmoid 与 tanh：函数族、值域与对称性。

参数影响 z，输出再影响损失。sigmoid 的导数为：

σ′(z) = σ(z)(1 − σ(z))

训练时，sigmoid 提供光滑、可导的输出，配合损失函数计算梯度；预测时，仍可按阈值把概率转成类别。

第 4 讲 · 分类与概率输出

0–1 损失：判对记 0

上一页把概率 p 用阈值变成类别。现在先定一把最直接的评分尺：判错记 1，判对记 0，这叫错分损失（0–1 loss）。

z = wᵀx + b，p = σ(z)，ŷ = 1[p ≥ 0.5] = 1[z ≥ 0]

1[条件]表示条件成立时取 1，否则取 0。单样本损失和 n 个样本的平均错分率为：

ℓ₀₋₁ = 1[ŷ ≠ y]，　L₀₋₁ = (1/n)Σᵢℓ₀₋₁,ᵢ

右图固定真实标签 y=1：p<0.5 时判错，损失为 1；p≥0.5 时判对，损失为 0。阈值两侧都是平的：dℓ₀₋₁/dz=0（z≠0）；到 z=0 的跳变处，导数不存在。梯度下降因此拿不到连续的更新方向。

📉 预测从 p=0.1 改到 p=0.4，错分损失变了吗？梯度下降能读到什么？

参考答案

没有变，仍是 1；阈值左侧梯度为 0，无法提示参数该朝哪边调整。

分类对错仍适合做最终评价；训练时还要找能提供更新信号的损失。下一页看把概率与 0/1 标签直接作平方差。

第 4 讲 · 分类与概率输出

MSE：平方误差接到概率上

回归里用平方误差；分类也可以把标签 y 当作 0/1 数值，比较模型给出的概率 p 与标签相差多少。单样本损失及全体样本平均为：

ℓMSE = (p−y)²；　LMSE = (1/n)Σᵢ(pᵢ−yᵢ)²

求导先对概率，再沿 sigmoid 回到分数：
dℓ/dp = 2(p−y)，　dp/dz = p(1−p)
δ = dℓ/dz = 2(p−y)p(1−p)

∇wℓ = δx，　∂ℓ/∂b = δ；　全体样本再取平均

优点是熟悉、公式直观；局限在链式法则的 p(1−p)：真实 y=1 而模型很自信地给 p≈0 时，δ≈0。预测明明错得很有把握，参数更新信号却变弱。

🔬 为什么平方差在概率 p 上有明显误差，传回 z 的梯度却可能很小？

参考答案

损失对 p 的导数还要乘上 sigmoid 导数 p(1−p)；当 p 接近0或1时，这一项接近0，会压小对 z 的梯度。

右图固定真实标签 y=1，横轴是模型预测为正类的概率 p；此时真实类别概率 q=p。y=0 时 q=1−p，MSE 损失曲线相同。MSE 可以用于分类，这里说明它接入 Logistic 回归后的一种优化局限。

第 4 讲 · 分类与概率输出

交叉熵：惩罚自信的错判

训练时，我们希望模型给真实类别较高的概率。令 q 表示真实类别概率：y=1 时 q=p，y=0 时 q=1−p。概率越低，惩罚越大：

ℓCE = −ln q = −[y ln p +(1−y)ln(1−p)]

求导仍沿链式法则：
dℓ/dp = −y/p +(1−y)/(1−p)，　dp/dz = p(1−p)
δ = dℓ/dz = p−y

∇wℓ = (p−y)x，　∂ℓ/∂b = p−y；　全体样本再取平均

真实 y=1 时，p=0.9 的损失约 0.105，p=0.1 时约 2.303。错得越自信，惩罚越大；自信错分端的梯度大小仍趋近 1。与 MSE 相比，它在这里保留了更明确的更新信号。

注意：极低真类概率会造成很大损失，标错的样本也可能强烈影响训练，因此要核对标签质量。

🧮 真实 y=0、模型给 p=0.9，损失看哪个概率？数值是多少？

参考答案

看真类概率 q=1−p=0.1，损失为 −ln(0.1)≈2.303。

ln 表示自然对数。右图同时展示真实标签 y=1 与 y=0，横轴是模型预测为正类的概率 p；对应的真类概率分别是 q=p 与 q=1−p。上图为损失，下图为 |dℓ/dz|。

最大似然（Maximum Likelihood）：为观测数据选择参数

上一页用交叉熵评价一个预测。现在问：如何评价一组参数对整批标签的解释能力？

训练集记作 D={(xi,yi)}。标签 yi 已经观测到；模型参数 θ 给出条件概率 pi=P(Yi=1|xi;θ)。

对 0/1 标签的伯努利分布（Bernoulli distribution），观测到真实标签的概率是：

P(yi|xi;θ)=piyi(1−pi)1−yi

若假设给定特征后，各样本标签条件独立，整批数据的似然函数（likelihood function）定义为：

L(θ;D)=P(y1,…,yn|X;θ)=∏i=1npiyi(1−pi)1−yi

最大似然估计（Maximum Likelihood Estimation, MLE）选择让 L(θ;D) 最大的参数：

θ̂MLE = argmaxθ L(θ;D)

在同一假设下：最大化似然 = 最小化负对数似然 = 最小化平均交叉熵。

−(1/n) ln L(θ;D) = 平均二元交叉熵

似然不是“参数的概率”，而是固定数据 D 后、把 θ 当变量的函数。证明：Stanford CS229 Notes §5。下一页算一个具体例子。

第 4 讲 · 分类与概率输出

另一种分类方法：kNN（k-Nearest Neighbors）

Logistic 回归通过参数和 sigmoid 给出类别概率；kNN 是本章介绍的另一种分类方法：它不先学一条公式，而是根据邻居来判断新样本。

规则：新点看最近的 k 个邻居，哪一类更多就判哪类。本实验 k=3。图中金色星是新点，三条线连向“蓝、蓝、红”三个邻居；2 比 1，所以判蓝。

概率：2 蓝 1 红，所以 P(蓝)=2/3；投票比例就是 kNN 的概率。kNN 不迭代拟合权重，而是保存训练样本，预测时再找邻居。

k 是复杂度旋钮：k=1 容易过拟合；k 越大，边界越平滑；k=全体时退化为多数类基线。距离计算前也要做标准化。

维度预警：特征维数一高，“最近的邻居”就不那么近；第 9 章会展开维度灾难。延伸阅读：Durrant & Kaban, “When is ‘nearest neighbour’ meaningful?”（Journal of Complexity, 2009）。

参考答案

kNN 是懒惰学习（lazy learning）：保存训练样本，预测时再找邻居，不迭代拟合分类权重。

暴力搜索的成本

n：训练样本数，d：特征数，m：查询样本数。

阶段主要成本
读取、复制训练数据O(nd)
单次预测O(nd)
预测 m 个样本O(mnd)
保存训练数据的空间O(nd)

上表采用线性选择算法找近邻；投票需 O(k)。标准化、建索引另计。

UCI 信用卡违约数据：训练集 18,000 人、8 个特征；暴力查询一个客户，需算 18,000 次八维距离。

与急切学习（eager learning）相对

急切学习先拟合模型再预测，如 Logistic 回归。kNN 的 training-free 指不拟合分类权重，但仍需保存数据、标准化和选择 k。

空间索引（spatial index）

KD-Tree、Ball-Tree 组织样本以减少距离计算。选型看样本数与维数、数据结构、k、查询量。

高维可能削弱 KD-Tree 的优势；k 大时剪枝减少，查询少时建树未必划算。

Ball-Tree 在结构良好的高维数据上仍可能有效；auto 是启发式选择，不保证最快。详解见 Notebook。依据：sklearn：算法选择 · Ball Tree。

第 4 讲 · 分类与概率输出

第三种分类方法：朴素贝叶斯（Naive Bayes）

朴素贝叶斯（Naive Bayes）不直接学习一条决策边界，而是分别学习“每一类长什么样”：新样本来了，比较它更像哪一类。这是一种生成式视角（generative view）。

其中，y 是类别，x 是新样本，xj 是第 j 个特征。对一个新样本，分类器这样做：

  1. 分别打分：对“违约”和“未违约”各算一次“先验 × 特征画像”的分数。
  2. 比较分数：哪个类别的分数更大，就认为新样本更像哪个类别。
  3. 输出结果：直接取分数最大的类别；如果还需要概率，再把各类别分数归一化。

“朴素”指一个简化假设：给定类别后，各个特征可以分别统计、再组合。这个假设未必完全真实，但换来了很快的训练和一个可用的基线。

💭 Logistic、kNN、朴素贝叶斯，三者分别“学”的是什么？

参考答案

Logistic 学参数化边界，kNN 记住样本并看邻居，朴素贝叶斯学习各类别的特征画像。

没见过，不等于不可能：拉普拉斯平滑

回到信用卡违约任务：新客户的特征中，可能出现训练数据里某一类从未见过的组合。

朴素贝叶斯要把各个特征概率相乘：

P(x|y)=∏jP(xj|y)

如果某个特征在“按时还款”类中的计数为 0，那么：

P(xj|按时还款)=0　⇒　P(x|按时还款)=0

这会让该类别被“一票否决”，即使其他特征都很像。

小故事：一条 S 形曲线的 180 年

1838 年，比利时数学家维尔胡斯特（Pierre-François Verhulst）研究人口增长：马尔萨斯的指数增长没有上限，与现实不符。他给指数项加了一个“饱和”修正，得到一条先快后慢、最终持平的 S 形曲线，1845 年命名为 logistique（logistic）。

此后约 80 年，这条曲线少有人提起。1920 年，Pearl 与 Reed 在研究美国人口增长时把它重新找了出来；1944 年，Berkson 把它用于生物剂量反应（bio-assay），logistic 回归从此进入统计学工具箱。今天它是经典的激活函数（activation function）之一，二分类输出层仍在用；sigmoid 泛指这一族 S 形曲线，logistic 是其中最常用的一条，两个名字今天都在用。

小故事：拉普拉斯与日出问题

传说有人问数学家拉普拉斯：太阳明天升起的证据是什么？他答得干脆：若一件事过去 n 天每天发生，按他的法则，明天发生的概率是 (n+1)/(n+2)。哪怕按有记载的历史取 n，这个数几乎等于 1，但永远不会是 1。

(n+1)/(n+2) 是“给计数加一”的祖先：上一页的拉普拉斯平滑给每个计数加 alpha，思想上同一件事。不给任何一个类别 0 的计数，因为 0 意味着“绝无可能”，而经验告诉我们，没有什么是绝无可能。

小注：这是拉普拉斯用来说明“过去的观察如何影响未来判断”的思想实验；“有人问拉普拉斯”是后来的故事化说法。延伸阅读：Wikipedia：Laplace's rule of succession · Wikipedia：Sunrise problem · Laplace，《Essai philosophique sur les probabilités》（1814）。

两种分类思路：学边界，还是学画像？

Logistic 回归看到客户特征后，直接学习“违约 / 未违约”的分界线：新客户落在哪一侧，就判断哪一类。

朴素贝叶斯则分别学习两类客户的特征画像：违约客户通常有什么特征，未违约客户通常有什么特征。新客户来了，再比较它更像哪一类。

两种方法都能完成分类，但学习的对象不同：一个学边界，一个学类别画像。

“What I cannot create, I do not understand.”

—— Richard Feynman（费曼留在黑板上的话；Caltech 资料）

今天的大语言模型（LLM）也属于广义的生成模型：它学习文本 token 的条件分布 P(xt|x<t)，再逐个 token 生成文本。这里与朴素贝叶斯的共同点是“建模数据分布”，但模型对象和规模完全不同。

第 4 讲 · 分类与概率输出

判别式与生成式：两条概率路线

判别式模型学习如何根据特征判断类别；生成式模型学习数据分布，分类时可通过数据与类别的联合分布推断类别。

判别式模型 （discriminative model）

直接学习类别概率 P(Y|X)，或学习分类边界。

p(x) = σ(wTx + b)
估计 P(Y=1|X=x) → 按阈值分类

其他例子：kNN（近邻投票）、支持向量机（SVM）、感知机；
决策树 / 随机森林（decision tree / random forest）。

生成式模型 （generative model）

在分类中，先学习联合分布 P(X,Y)：类别比例 + 各类特征分布。

P(X,Y) = P(Y)P(X|Y)
贝叶斯公式：P(Y|X) ∝ P(X|Y)P(Y)

其他例子：线性 / 二次判别分析（LDA / QDA，分类）；隐马尔可夫模型（HMM，序列建模）；GPT 类大语言模型（LLM，文本生成）。

图中两条路线都能分类，学的对象不同。生成式模型可按学到的分布采样特征；Logistic 回归给定特征后预测标签，不能凭它生成特征。

朴素贝叶斯的额外假设：给定类别后各特征条件独立（conditional independence），P(X|Y) = ∏j=1dP(Xj|Y)。

多分类怎么办：OvR 与 softmax 预告

本章的 p 一律是“下个月违约”的概率，因为任务只有两类。第 2 章的 digits 有 10 类，怎么办？一条常用路线：一对多（one-vs-rest，OvR）。

OvR 的做法：把 K 类拆成 K 个二分类器，第 i 个只回答“是不是第 i 类”，学一组自己的权重；新样本来了，看哪个二分类器喊“是”喊得最响，就判哪类。

权重形状能看出拆分：本章二分类一组 8 维权重，coef_ 形状 (1, 8)（Logistic 训练单元）；按 OvR 做 10 类 digits，每类一行，权重就是 10 行×64 列。

另一种做法是用 softmax 一次算出每个类别的概率，这些概率加起来等于 1。我们讲到神经网络时再介绍它。

📣 OvR 会不会出现两个二分类器同时喊“是”？

参考答案

会：所以要比谁的概率更高；这正是它和 softmax 路线的差别之一。

错例阅读三步法：一次违约漏报

验证集有一位客户，真实标签是“违约”，模型给出的违约概率为 0.247。因为它低于 0.5，模型把客户判成了“未违约”——这是一次漏报。

  1. 先记事实：概率是多少，真实标签是什么，模型最后做了什么判断。
  2. 再提一个猜想：是特征不够？标签有噪声？还是这类客户样本太少？一次只讨论一个原因。
  3. 最后想办法验证：补充同类样本、检查标签，或重新训练后再看结果。没有验证之前，只能叫猜想。

0.247 不代表风险为零，只是没有超过默认阈值 0.5。第 5 章会继续讨论如何调整阈值。
